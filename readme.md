# APM review plot script for zotero users
1. please submit zotero .csv raw data into **data** folder first, this include (output.bbl, data.json, data.csv. If you want to plot the figures based on topologies, topology.csv is also needed)
2. run **APM_review_bibcombiner.py** to get all the reference number into your raw data, see it in good.csv
3. run **APM_reiew_reprocess.py** to get all the final datafram to create figures, check proccessed data in parsed_data.csv!
4. now run all APM_review_plot script to get your figures, they are located in **output** folder
